# **App Name**: ReelsDeploy

## Core Features:

- Reels Feed: Display a vertical list of Reel cards with brand name, category, and location using static video/image URLs.
- Reel Card Actions: Provide 'View Details' and 'Deploy to Screens' CTA buttons on each Reel card.
- Details Screen: Display a full-screen video with dummy stats (views, CTR) and a 'Deploy' button.
- Data Fetching: Fetch mock JSON data for Reels from a public mock API.
- Pull-to-Refresh: Implement pull-to-refresh functionality for the Reels feed.
- Loading and Error States: Display appropriate loading and error states when fetching data.

## Style Guidelines:

- Primary color: Deep sky blue (#42A5F5) for a modern and engaging feel.
- Background color: Very light blue (#F0F7FF) to ensure comfortable readability and visual clarity.
- Accent color: Soft green (#66BB6A) to contrast with the primary and indicate active or deployable elements.
- Body and headline font: 'PT Sans' sans-serif, providing a clean and modern look for the feed.
- Use a set of clear and minimalistic icons for categories and actions.
- Maintain a clean, consistent spacing and alignment throughout the app.
- Implement smooth transitions and subtle animations for UI elements like loading states and button presses.
